# UbuntuCare Health Platform

## 1.0.0 (Initial Release)

- Complete rebuild from NVIDIA Ambient Healthcare Agents blueprint
- Removed all NVIDIA NIM dependencies
- Replaced with open-source models (DeepSeek-R1, Qwen3, Whisper, Coqui TTS)
- Added Zambia-specific modules (disease surveillance, CHW, drug supply chain)
- Added multi-language support (English, Bemba, Nyanja, Tonga, Lozi)
- Added offline/edge deployment support
